## 💪 使用场景

### 场景1：清晨Mysore练习
> 早上6点起床，打开熬汤日记，选择"Mysore自我练习"，点击开始，专注练习。练习结束后，记录今天的身体感受，看到月相日历上又多了一个黄色小亮点，继续坚持！

### 场景2：跟练口令课
> 晚上跟着老掌门人的口令练习，选择"一序列"口令跟练，自动播放音频，边听边练。练习结束，记录突破时刻："今天终于完成手倒立了！"

### 场景3：查看进步
> 练了半年，打开数据统计，看到累计练习120天，累计熬汤180小时，平均每次90分钟。回顾时间线，看到自己从只能练半序列到如今完成全序列，满满的成就感！

## 📱 使用方法

### 开始练习
1. 选择练习类型（Mysore/口令课/自定义）
2. 点击"开始练习"
3. 专注练习
4. 练习结束，记录觉察
5. 保存完成

### 查看历史
1. 点击日历查看打卡记录
2. 点击时间线查看详细记录
3. 可编辑或删除任意记录

### 查看统计
1. 点击"数据统计"
2. 查看累计天数、累计时长
3. 看到自己的进步
