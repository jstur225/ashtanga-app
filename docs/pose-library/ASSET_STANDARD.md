# 一序列人物素材标准

## 固定角色

- 成年女性，纤细、健康，保持真人比例。
- 深色中高马尾，发量、长度和发色保持一致。
- 匿名脸，只保留眉毛，不添加个性化五官。
- 浅米白背心 `#EDE5D6`。
- 森林绿短裤 `#2A4B3C`。
- 服装使用完整纯色色块，不表现胸部、胯部、臀部或裆部轮廓，不添加勒痕、接缝、透明效果和复杂阴影。
- 画风为平面纸感编辑插画：流畅轮廓、少量大色块、轻微纸纹、克制的肌肉线条。

角色四视图：`output/primary-series-ip-v1/reference/ip-character-turnaround.png`

## 正式素材格式

- 母版：1024×1024 RGBA PNG。
- 背景：透明。
- 四角必须完全透明。
- 人物手脚完整，四周至少保留 24px 安全边距。
- 只允许等比例缩放和平移，禁止横向或纵向拉伸。
- APP 详情图：最长边 1024 的 WebP。
- APP 缩略图：320×320 WebP。

## 人物尺度规则

人物尺度以拜日 A 山式中的固定角色为基准，不以每张图片的外接框高度为基准。

- 同一角色的头部、躯干、手臂和腿长应保持相近视觉尺寸。
- 举手、抬腿和宽站动作可以占用更大的外接框，不能为了“图片等高”把人物缩小。
- 横向或大幅展开动作只有接近安全边距时才整体等比例缩小。
- 前屈、宽站、单腿站立、举手弓步分别在同类动作之间校准。
- 拜日 A/B 中的重复动作必须复用同一素材，不能重新生成近似版本。

## 对齐规则

- 站立、前屈和弓步动作以主要脚底落地点为基线。
- 手脚同时落地时，手掌和脚底必须处于同一地面关系。
- 站立体式正式基线为 `y=959`。
- 宽站姿以双脚中点进行水平居中。
- 单腿站姿以承重脚为基线，再按人物视觉重心居中。
- 倒立和横卧动作不套用脚底基线，应在对应分类内建立独立对齐标准。

## 命名与复用

- 文件名使用小写英文和连字符。
- A/B/C/D、1/2 和 `-01/-02` 等原始变体标记保持不变。
- 同一动作在序列中重复出现时复用同一个正式文件。
- 正式路径和文件名一旦进入数据索引，返修时只替换内容，不改变路径、分类或顺序。
- 暂时无法正确生成的动作使用明确占位素材，不让错误人体结构进入正式页面。

## 自动验收

站立体式运行：

```powershell
node scripts/build-standing-v3-full.mjs
node scripts/build-standing-v3-review-sheet.mjs
node scripts/validate-standing-v3-full.mjs
node scripts/publish-standing-v3-full.mjs
```

验收至少包括：

- 数量与索引一致。
- 1024×1024 RGBA。
- 透明四角。
- 无重复文件。
- 主要落地点符合分类基线。
- 无裁切、额外肢体、断肢和明显关节错误。
- 人物方向、马尾重力、服装安全和角色色板一致。
- 联系表人工核对通过后才推送部署。
