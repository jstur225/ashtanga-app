- 图片使用完整正方形区域，不再使用圆形裁切。
- 小卡片保留圆角，卡片与页面使用统一背景色，不使用阴影边框。
- 中文标题位于图片下方。
- 顶部栏目使用与底部 Tab 栏一致的半透明磨砂、边框、圆角和阴影；列表内容从浮层下方滚过，可透过磨砂层看到。
