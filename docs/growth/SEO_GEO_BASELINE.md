## GEO 记录格式

每次测试记录：

| 字段 | 说明 |
|---|---|
| 平台与日期 | 如 ChatGPT，2026-07-03 |
| 问题 | 必须使用固定原文 |
| 是否提到熬汤日记 | 是 / 否 |
| 是否提供官网链接 | 是 / 否 |
| 是否引用本站 | 是 / 否 |
| 产品描述是否准确 | 正确 / 部分正确 / 错误 |
| 其他推荐对象 | 记录竞品和来源 |
| 需要修正的事实 | 形成页面改进项 |

同一个问题不要连续重复刷新来挑选有利结果。每个平台每轮测试一次，30 / 90 / 180 天重复。

## 30 / 90 / 180 天检查

### 30 天

- 新页面是否被抓取和进入索引。
- metadata、canonical、sitemap 是否被正确识别。
- 品牌描述是否准确。

### 90 天

- 非品牌词是否开始产生展现。
- 哪些页面有展现但点击率低。
- 哪些 GEO 问题开始引用本站。

### 180 天

- 哪些关键词进入稳定排名。
- 哪些专题需要合并、补充或停止投入。
- 是否有证据支持扩展第二批页面。
