# 小程序非支付功能集中验收清单

> 更新日期：2026-07-28  
> 目标 AppID：`wx36f4826bc022d43f`  
> 范围：首版除微信支付以外的全部用户路径

这份清单用于一次性真机验收，不再按按钮零散测试。自动化通过只能证明数据和页面接线没有明显回归，照片、音频、Storage、相册权限和微信网络环境仍必须在真机确认。

## 0. 测试准备

- 微信开发者工具“详情”显示新 AppID。
- 准备三种状态：游客、登录 FREE 账号、有效 PRO/试用账号。
- 准备一台真机，并能够在同一邮箱账号的网页版核对数据。
- 准备 1 张小图、9 张合法图片、1 张超限大图和一段长笔记。
- 开启微信合法域名校验；如果失败，先完成新 AppID 的公众平台域名配置。
- 新 AppID 的 request 合法域名至少包含 `https://ash.ashtangalife.online`、`https://xojbgxvwgvjanxsowqik.supabase.co`；downloadFile 合法域名包含 `https://ash.ashtangalife.online`。修改后台后在开发者工具“详情 → 域名信息”刷新并重新编译。
- 在项目根目录执行 `npm run check:weapp-release`，确认源码包低于 1.9 MiB，AppID、HTTPS、publishable key、sitemap 和开发者工具安全开关全部通过。
- 在 Supabase SQL Editor 执行 `supabase/rls_release_audit.sql`，确认没有“RLS 未开启但 anon/authenticated 仍有权限”的业务表。

失败时保留三项证据：页面截图、控制台第一条完整红色错误、数据管理中的运行日志。不要只记录“失败了”。

## 1. 游客完整路径

1. 清空新 AppID 的本机缓存后首次打开：显示落地页。
2. 点击开始；觉察日记出现一条教程笔记。
3. 新增一条无照片练习，确认日历、时光轴和“我的”统计立即变化。
4. 关闭并重新打开小程序，记录仍存在；落地页不重复出现。
5. 编辑、删除记录，三个页面的数据同步变化。
6. 点击照片入口：必须要求绑定邮箱，不能打开系统相册。
7. 触发第 4 个练习选项、第 2 种标注、非免费色阶和自定义唱诵时长：显示同一会员权益 Sheet，不破坏免费记录闭环。

通过标准：游客全程不登录也能完成练习闭环；所有数据只留在新 AppID 的本机空间。

## 2. FREE 账号完整路径

1. 登录既有邮箱账号：从 Supabase 恢复练习、资料和会员状态，游客数据合并提示只出现一次。
2. 新增一条练习并上传 1 张不超过 5 MB 的照片：表单逐步显示读取、上传、成功，成功前保存不可用。
3. 一次选择 2 张或超过剩余额度：整批拒绝，不能偷偷保留其中 1 张。
4. 保存后直接进入觉察日记，不闪回今日练习；日历、记录和照片立即出现。
5. 网页版刷新后只出现一条相同记录，照片可以打开。
6. FREE 只允许 3 个练习选项、1 种标注、第 3 色阶、每条 1 张照片/5 MB、固定 60 秒唱诵倒计时。

通过标准：本机先显示、云端随后一致；失败时保留本机数据和可重试任务。

## 3. PRO/试用账号完整路径

1. “我的”正确显示 PRO、会员类型、到期日和剩余天数。
2. 同一条记录依次添加至 3、4、9 张照片：
   - 1～3 张为三列 1:1 方图；
   - 4～9 张为单行横向滑动；
   - 9 张全部上传后才能保存。
3. 一次选择第 10 张或超过剩余额度：整批拒绝。
4. 验证 11 个练习选项、9 种标注、4 个色阶、自定义唱诵倒计时。
5. 模拟会员过期后，既有超额选项、标注和照片仍可查看，但不能继续新增超额内容。

通过标准：PRO 权益全部来自同一能力策略；降级不删除用户数据。

## 4. 离线、同步与账号隔离

1. 登录账号后断网新增、编辑、删除各一条记录：本机立即变化，云状态显示待同步。
2. 恢复网络点击立即同步：pending 归零，网页版结果一致且无重复记录。
3. 照片上传中断后保留失败态；恢复网络重试后替换为 OSS HTTPS 地址。
4. 照片逐张同步时只有照片状态变化；日历格、统计卡和标注不得每 600ms 闪动或重排。
5. 退出账号回到游客：不得显示账号数据。
6. 登录另一个账号：账号 A、账号 B、游客三份本机工作区互不串线。
7. Session 过期时应自动刷新；无法恢复时进入可理解的重新登录路径，不能无限读取。

## 5. 分享卡

### 月度统计卡

- 预览居中，无右侧白框或左偏。
- 保存图片清晰，月历圆点、统计和品牌信息完整。
- 关闭后底部 Tab 与页面滚动恢复。

### 单条觉察笔记卡

- 点击后立即用当前缓存打开，不等待全年统计网络请求。
- 短笔记不产生过多空白；长笔记和 1/9 张照片仅卡片纵向滚动。
- 卡片外滑动时背景页面不移动；底部返回/保存始终固定。
- 不出现网页真源没有的缩放控件。
- 保存时才生成 Canvas；保存图片内容与预览一致且清晰。

## 6. 口令音频

1. 新 AppID 首次进入今日练习即开始预热，选择一序列后加载状态文案真实。
2. 冷缓存第一次播放记录等待时间；加载期间练习计时不得提前开始。
3. Wi-Fi 完整缓存后关闭并重启小程序，第二次优先使用本机缓存。
4. 唱诵与口令互斥，提示文案为“口令包含唱诵，不能同时开启”。
5. 断网或缓存损坏时能够回退远端/显示错误并重试，不长期转圈。
6. 慢于预期时导出运行日志，检查 `guided_audio` 的来源、缓存状态、可播耗时和缓冲次数。

- 清空本地数据经过三阶段确认；不退出登录、不删除 Supabase 云端数据、不重置落地页已读状态。

## 8. 非支付完成门

只有同时满足以下条件，才进入微信支付开发：

- 自动化、TypeScript、lint 全部通过。
- 游客、FREE、PRO 三条真机路径通过。
- 新 AppID 开启合法域名校验后，登录、同步、照片和音频无域名错误。
- 分享卡和相册保存通过真机权限测试。
- 不存在“下一步接入”占位按钮或无响应的非支付入口。
- 所有失败都有明确提示、可恢复路径和足够的运行日志。
- 运行日志包含脱敏后的运行错误、未处理 Promise 与同步错误，不出现邮箱原文、JWT、Bearer 或服务端密钥。
- Supabase RLS 只读审计已人工完成，客户端没有 service role/secret key。
