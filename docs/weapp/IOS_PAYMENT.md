# iOS 虚拟支付（Apple 支付）说明

更新日期：2026-08-14

## 背景

- 微信小程序 iOS 端虚拟支付于 2025-11 开放（"时隔八年破冰"），工具类目可接入；2026-04-01 起微信要求涉及虚拟商品的**全终端强制接入**。
- 1.0.0 提审通过；微信后台已启用 **Apple IAP 支付**开关。
- 客户端已移除 iOS 购买拦截（提交 606f4780）：iOS 用户走同一 `wx.requestVirtualPayment`，平台自动路由 iOS→Apple 支付、安卓/鸿蒙/Windows→微信支付。
- 道具（pro90d / pro365d）Android/iOS **双端互通**，无需在微信后台重建。
- 服务端 happy path 无需改动：下单 → 轮询 `/xpay/query_order` 确认到账，对 Apple 订单同样生效（env=0 现网）。

## 用户侧条件（Apple 支付）

- iPhone / iPad，iOS 15 及以上；
- 微信客户端 8.0.68 及以上；
- 商品最低 1 元；
- 仅支持**中国大陆 App Store 账户**；
- Apple 支付**不支持沙箱环境**，仅现网（本项目已是 env=0）。

## 费率 / 结算 / 退款

- 费率：标准 17%（Apple 12% + 腾讯 5%）；**2026 年腾讯技术服务费限时减免为 0** → 当前 iOS 实际约 **12%**。
- 结算：Apple 月结后 45～60 天结算给腾讯，腾讯划转虚拟支付账户后即可提现。
- 退款：Apple 支付**不支持开发者主动退款**，用户须在 App Store 申请；微信会推送退款问询（`xpay_subscribe_ios_refund_query_notify`），当前**未实现响应接口** → 退款由 Apple 决定（对用户友好）。可选后续实现。

## 真机测试清单（必须，会真扣款）

1. iPhone（iOS 15+）、微信 8.0.68+、中国大陆 App Store 账户；
2. 上传体验版后在 iPhone 上打开；
3. 我的页 → 会员卡「开通/续费」→ 应拉起 **Apple 支付**；
4. 完成付款 → 会员状态变为 Pro（有效期显示）；
5. 订单中心页出现该订单（支付渠道为 Apple 支付）；
6. 测一次**取消支付**：关掉 Apple 支付弹窗 → 订单显示"已关闭/未支付"；
7. 测完到 App Store 申请退款测试款。
