## 规则

- 每次修复回归必须留下永久测试。
- 新模块所有公共操作和错误分支必须有测试。
- 状态机每条合法转换必须覆盖。
- 无法自动化的项目必须记录原因、风险和人工验证方法。
- 测试数量不是完成标准，矩阵中的高风险缺口清零才是。
