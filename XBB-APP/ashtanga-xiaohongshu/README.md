# 小红书阿斯汤加内容生产系统

从碎片化创作升级到系统化创作。

---

## 🎯 核心理念

**❌ 碎片化创作**：
有想法 → 问AI → 得到答案 → 发布 → 忘记

**✅ 系统化创作**：
有想法 → 记录选题 → 检索素材 → 复用框架 → 发布 → 数据复盘 → 反哺方法论

每次创作都在给系统添砖加瓦。

---

## 🚀 快速开始

### 第一次使用

1. **阅读操作手册**：`OPERATIONS.md`
2. **浏览素材库**：`内容素材库/` 目录
3. **记录第一个选题**：对 Claude 说"生成文案"

### 日常工作流程

```
飞书表格(🟡待生成) → 生成文案 → 飞书知识库(🟠待审核) → 审核 → 发布 → 数据复盘
```

## 🤖 AI 自动化能力

| 指令 | 说明 |
|-----|------|
| **"生成文案"** | 自动找🟡待生成选题，调用NotebookLM生成，同步到飞书 |
| **"保存到知识库"** | 将文案保存到飞书知识库，更新链接 |
| **"让LM重写 [要求]"** | 重新调用NotebookLM生成文案 |
| **"我发布了 [链接]"** | 记录发布链接，状态改🔵已发布 |
| **"列表"** | 显示所有选题状态统计 |

## 📊 数据驱动流程

### 发布后的动作

每次发布后，必须做"数据复盘"：

1. 记录数据（阅读、点赞、收藏、评论）
2. 文稿移动到"已发布"
3. AI 自动分析数据
4. 更新统计文件
5. 反哺方法论

### 每月复盘

- 每月查看 `内容数据统计/` 文件
- 分析什么选题、标题、文案角度数据好
- 更新 `方法论沉淀/` 文件

---

## ✅ 使用建议

### 要做的

1. **每次创作前，先检索素材库** - 避免重复造轮子
2. **数据好的内容，标记为可复用** - 添加到 `爆款文稿库/`
3. **每次发布后，记录数据** - 数据驱动迭代
4. **定期复盘** - 持续优化方法论

### 不要做的

1. 不要每次都从零开始创作
2. 不要忽视数据记录
3. 不要只问不记录
4. 不要让素材库成为摆设
