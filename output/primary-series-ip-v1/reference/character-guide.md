# 女性 IP 角色与画风规范 v1

## 角色

- 成年女性，纤细、健康、轻微运动线条，保持真人比例。
- 中等暖棕肤色；深炭色中高马尾，长度、发量和发色保持一致。
- 匿名脸：只保留两条眉毛，不画眼睛、鼻子、嘴巴或个性化特征。
- 浅米白无袖短款运动背心 `#EDE5D6`。
- 森林绿贴身瑜伽短裤 `#2A4B3C`。

## 服装安全规则

- 背心和短裤必须是完整、纯色、不透明的大色块。
- 不画胸部、下胸线、乳沟、臀部、胯部、裆部或内腿敏感轮廓。
- 不画罩杯、勒痕、接缝、缝线、褶皱、纹理、渐变、高光或阴影。
- 服装只能由干净的外轮廓定义。

## 画风

- 平面纸感编辑插画，流畅连续的外轮廓和少量大色块。
- 背景统一为 `#F9F7F2`，保留轻微温暖纸纹。
- 肤色和头发允许极轻纸纹；服装保持视觉上的纯色。
- 只在裸露且非敏感的身体区域使用少量宽阔阴影，不刻画复杂肌肉。
- 禁止写实、3D、动漫、碎三角形、密集线稿、排线和个性化五官。

## 素材规范

- 输出：PNG，1024×1024。
- 人物完整居中，手脚不得裁切，保持统一安全边距。
- 姿势以对应原素材为准，允许修复裁切和轻微美化人体曲线。
- 不添加动作名称、教学文字、Logo、水印、道具或场景。
