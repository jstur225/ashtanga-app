# 单张体式生成提示词模板

每张生成同时引用：

1. `ip-character-turnaround.png`：角色、服装、色板和画风参考。
2. 对应的 `output/primary-series-assets/<section>/<filename>`：姿势参考。

固定要求：

- 只生成一个与角色设定图一致的成年女性。
- 严格保留动作参考的身体朝向、四肢关系和整体轮廓，允许修复原图裁切和轻微美化曲线。
- 中高深炭色马尾应顺应重力和动作方向。
- 匿名脸只保留眉毛，不画其他五官。
- 背心 `#EDE5D6`、短裤 `#2A4B3C`；服装内部无任何敏感轮廓、接缝、褶皱、阴影或高光。
- 平面纸感编辑插画，流畅轮廓、少量大色块、真人比例。
- 1024×1024 构图，完整手脚、统一安全边距，背景 `#F9F7F2` 和轻微纸纹。
- 无文字、Logo、签名、水印、道具、场景、额外人物或多余肢体。
