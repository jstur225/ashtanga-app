## 修复内容

### 1. 错误历史记录功能 ✅

**问题**: 日志导出时 `errorHistory` 永远是空数组，因为 `window.__errorHistory` 从未被设置。

**解决方案**:
- 在 `useSync.ts` 的 `addLog` 函数中，当记录错误时，同时将错误写入 `localStorage.__errorHistory`
- 在日志导出时，从 `localStorage` 读取错误历史

**代码变更** (`hooks/useSync.ts`):
```typescript
// 在 addLog 函数中添加
if (status === 'error' && typeof window !== 'undefined') {
  try {
    const existingErrors = JSON.parse(localStorage.getItem('__errorHistory') || '[]')
    const errorEntry = {
      timestamp: new Date().toISOString(),
      action,
      error: truncatedError,
      userAgent: navigator.userAgent.substring(0, 100),
      url: window.location.href
    }
    const newErrors = [errorEntry, ...existingErrors].slice(0, 20)
    localStorage.setItem('__errorHistory', JSON.stringify(newErrors))
  } catch (e) {
    // 忽略 localStorage 错误
  }
}
```

**代码变更** (`app/practice/page.tsx`):
```typescript
// 从 localStorage 读取错误历史
let errorHistory: any[] = []
try {
  const storedErrors = localStorage.getItem('__errorHistory')
  if (storedErrors) {
    errorHistory = JSON.parse(storedErrors)
  }
} catch (e) {
  errorHistory = [{ error: '读取错误历史失败', details: String(e) }]
}
```

### 2. 同步日志读取修复 ✅

**问题**: 日志导出时 `syncLogs` 永远是空数组，因为 `window.__syncLogs` 从未被设置。

**解决方案**:
- 从 `localStorage` 读取 `sync_logs`（这是 `useSync.ts` 中使用的键）

**代码变更**:
```typescript
// 从 localStorage 读取同步日志
let syncLogs: any[] = []
try {
  const storedLogs = localStorage.getItem('sync_logs')
  if (storedLogs) {
    syncLogs = JSON.parse(storedLogs)
  }
} catch (e) {
  syncLogs = [{ action: '读取同步日志失败', error: String(e), timestamp: new Date().toISOString() }]
}
```

### 3. Supabase 连接测试 ✅

**问题**: 日志中缺少 Supabase 服务器连接状态，无法判断同步失败是网络问题、服务器问题还是应用逻辑问题。

**解决方案**:
- 将 `handleExportDebugLog` 改为异步函数
- 在导出日志时，执行一个简单的 Supabase 查询测试（`user_profiles` 表的 `count` 查询）
- 记录连接状态、延迟（毫秒）和错误信息

**代码变更**:
```typescript
const handleExportDebugLog = async () => {
  // 先发起 Supabase 连接测试
  let supabaseConnectionTest = { status: 'testing', latency: -1, error: null as string | null }
  try {
    const testStart = Date.now()
    const { data, error } = await supabase.from('user_profiles').select('count', { count: 'exact', head: true })
    const latency = Date.now() - testStart
    if (error) {
      supabaseConnectionTest = { status: 'error', latency, error: error.message }
    } else {
      supabaseConnectionTest = { status: 'success', latency, error: null }
    }
  } catch (e: any) {
    supabaseConnectionTest = { status: 'exception', latency: -1, error: e?.message || String(e) }
  }

  // ... 其他日志收集逻辑

  // 添加到日志
  const supabaseConnection = {
    testStatus: supabaseConnectionTest.status,
    latency: supabaseConnectionTest.latency,
    error: supabaseConnectionTest.error,
    timestamp: new Date().toISOString()
  }
}
```

  }
