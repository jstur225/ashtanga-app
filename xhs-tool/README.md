# 小红书「阿斯汤加体式库」离线体验版

这是一个独立于正式站的纯静态小工具。它从 `../lib/pose-data.ts` 读取体式数据，
把正式站 WebP 图片转换为 JPG，并将可上传文件输出到 `dist/`。

## 本地手机测试

电脑和手机连接同一局域网后运行：

```powershell
cd xhs-tool
npm run build
npm test
npm run serve
```

命令会同时打印电脑地址和手机访问地址，默认端口为 `4178`。

小红书上传时使用 `release/ashtanga-pose-library-xhs-20260731.zip`。ZIP 的根目录已经直接包含 `index.html`，不要再给 ZIP 外面多包一层目录。

栏目映射：

- `surya-a` + `surya-b` → 拜日 A/B
- `standing` → 站立体式
- `seated` → 坐立体式
- `finishing` → 休息体式

后续正式体式库的数据或图片更新后，重新运行 `npm run build` 即可覆盖生成资源。
